# BrightSmile Dental Studio

React + Vite front end with a Supabase (PostgreSQL) backend — generated by ForgeAI.

## Run locally

```bash
npm install
npm run dev
```

The Supabase URL and anon key live in `.env.local` (see `.env.example`). The anon
key is safe in the browser: every table has row-level security enabled.

## Database

- **appointment_requests** — visitors can only SUBMIT (insert) rows — they can NOT read, update or delete any, not even their own; only STAFF read and manage them (on staff pages): patient_name, phone_number, email, preferred_service, preferred_date, preferred_time_slot, preferred_dentist, notes, status
- **patient_reviews** — visitors can only SUBMIT (insert) rows — they can NOT read, update or delete any, not even their own; only STAFF read and manage them (on staff pages): patient_name, treatment_received, rating, review_text, is_approved, review_date
- **clinic_services** — any visitor can READ; only STAFF can create/update/delete (on staff pages): title, slug, summary, detailed_description, starting_price_pkr, price_label, category, icon_name, is_featured
